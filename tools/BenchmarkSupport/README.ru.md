# Общая поддержка бенчмарков

Эта библиотека .NET 8 предоставляет проверку путей workspace, запуск процессов, хеширование исходников/сборок, переносимые метаданные оборудования, SVG-графики и общую цветовую шкалу отчётов. У неё нет CLI-точки входа и измеряемых нагрузок.

Запускайте проект, которому принадлежит нагрузка:

| Проект | Руководство | Область |
| --- | --- | --- |
| `SKECS.Benchmarks` | [Бенчмарки ECS](../../SKECS.Benchmarks/README.ru.md) | Микробенчмарки SKECS и пяти ECS, генерация исходников, проверки vendor и анализ |
| `SpaceBattle.Benchmarks` | [Игровые бенчмарки](../../SpaceBattle.Benchmarks/README.ru.md) | Headless-симуляция, desktop-замеры и анализ сохранённого состава |

Каждый проект содержит собственные измерения и генераторы отчётов. Библиотека содержит только общую инфраструктуру; команды между проектами не диспетчеризуются. Оба используют игнорируемый `artifacts/` для сырых данных и `artifacts/tooling` для кешей и временных файлов. Публикации содержат сгенерированные Markdown, SVG и итоговые таблицы.

[BenchmarkMachineInfo.cs](../BenchmarkMachineInfo.cs) и [BenchmarkMachineLabel.cs](../BenchmarkMachineLabel.cs) также используются игрой и измеряемыми проектами. Метаданные CPU получаются через поддерживаемые .NET API с резервным указанием архитектуры. Hardware capture записывает лимит доступной памяти GC, а не физическую RAM. Метка машины по умолчанию — `local-machine`; задавайте разные нейтральные `SKECS_BENCHMARK_MACHINE_LABEL` для разных компьютеров.

```sh
dotnet test tools/BenchmarkSupport.Tests/BenchmarkSupport.Tests.csproj -c Release
```

Тесты проверяют общую инфраструктуру и контракты генерации, валидации и отчётов обоих проектов. Генерация отчётов использует стандартную библиотеку .NET без Python, PowerShell и внешних графических библиотек. Измеряемые проекты сохраняют объявленные NuGet-зависимости; необязательным desktop-замерам требуется рабочее графическое устройство.
