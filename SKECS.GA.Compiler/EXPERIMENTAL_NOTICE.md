# SKECS.GA.Compiler experimental notice

This package lowers the supported C# subset into CPU and GPU artifacts.

GA conformance covers selected kernels, devices, and runtimes. A complete cross-runtime SpaceBattle replay baseline is still open. The isolated Unity CPU and GPU replay matched through tick 1,200, and its first difference from the browser reference occurred at tick 1. Treat deterministic results as specific to the tested workload, runtime, and device.
