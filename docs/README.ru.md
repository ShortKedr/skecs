# Карта документации

[Обзор проекта](../README.ru.md)

Эти руководства описывают текущую реализацию и опубликованные измерения.

## Использование SKECS

- [Установка пакета](skecs/INSTALL.ru.md): локальный NuGet, DLL для Unity и подключение в Godot C#.
- [Руководство библиотеки](skecs/README.ru.md): запросы, системы, владение и время жизни.
- [Оптимизации среды выполнения](SKECS_OPTIMIZATION.ru.md): прямое создание, аксессоры, сохранённое хранилище и диагностика.
- [Пример](../SKECS.Sample/Program.cs) и [тесты](../SKECS.Tests): исполняемые примеры и текущие контракты.

## Измерения

[Поддерживаемые инструменты](../tools/README.ru.md) охватывают CI, запуск и анализ бенчмарков, а также программный harness проверки.

| Нагрузка | Методика и результаты |
| --- | --- |
| Микробенчмарки пяти фреймворков | [Результаты и область измерения](benchmarks/current/REPORT.ru.md) |
| Наборы BenchmarkDotNet SKECS и диагностика API | [Дополнительные результаты](benchmarks/current/SUPPLEMENT.ru.md) |
| Воспроизведение микробенчмарков | [SKECS.Benchmarks](../SKECS.Benchmarks/README.ru.md) |
| Игровая нагрузка high на пяти реализациях ECS | [Отчёт Space Battle](space-battle/REPORT.ru.md) |
| Воспроизведение бенчмарков SpaceBattle | [SpaceBattle.Benchmarks](../SpaceBattle.Benchmarks/README.ru.md) |
| Старт desktop и Mean в HUD | [Сопоставленные замеры Release/headless](space-battle/DESKTOP_TIMING.ru.md) |
| Цветовые маркеры в отчётах и графиках | [Общая шкала сравнения](benchmarks/COLORS.ru.md) |

Перед сравнением результатов проверьте дату измерения, версии исходников, оборудование и конфигурацию. Сырые данные находятся в игнорируемых локальных артефактах; отчёты описывают записанное ПО и нагрузку.

Текущие внутренние спецификации и планы разработки хранятся в [приватном репозитории SKECS](https://github.com/ShortKedr/skecs-private).
